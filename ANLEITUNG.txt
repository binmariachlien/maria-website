## WICHTIG: Impressum & Datenschutz anpassen!

Öffne `impressum.html` und `datenschutz.html` mit einem Texteditor (z.B. Notepad) und ersetze:

```
DEIN_VORNAME DEIN_NACHNAME  →  z.B. Max Mustermann
DEINE_STRASSE HAUSNUMMER    →  z.B. Bahnhofstrasse 1
PLZ ORT                     →  z.B. 8000 Zürich
DEINE_EMAIL@beispiel.ch     →  z.B. kontakt@mariachlien.com
```

## Website hochladen (Vercel)

### Schritt 1: GitHub Repository erstellen
1. Gehe zu github.com
2. Klicke "New Repository"
3. Name: `maria-website`
4. Klicke "Create repository"

### Schritt 2: Dateien hochladen
1. Klicke "Add file" → "Upload files"
2. Ziehe ALLE 4 Dateien rein (index.html, impressum.html, datenschutz.html, profile.jpg)
3. Klicke "Commit changes"

### Schritt 3: Vercel verbinden
1. Gehe zu vercel.com
2. "Sign up with GitHub"
3. "Add New" → "Project"
4. Wähle dein Repository "maria-website"
5. Klicke "Deploy"

### Schritt 4: Domain verbinden
1. In Vercel: "Settings" → "Domains"
2. Füge "mariachlien.com" hinzu
3. Folge den DNS-Anweisungen (bei deinem Domain-Anbieter)
